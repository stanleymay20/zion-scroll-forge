# ScrollCritical Thinking Components

Revolutionary critical thinking and innovation components implementing "Come, let us reason together" (Isaiah 1:18).

## Components

### Core Components
- **CriticalThinkingDashboard**: Main hub for critical thinking activities
- **ReasoningChallenge**: Interactive critical thinking challenges
- **PropheticAssessment**: Spiritual alignment evaluation interface
- **InnovationLab**: Weekly innovation challenge workspace
- **DebateRoom**: Global collaboration and debate platform

### Supporting Components
- **ThinkingLevelIndicator**: Visual progress tracking
- **ScrollXPTracker**: XP rewards and achievements
- **EvidenceEvaluator**: Tool for analyzing evidence quality
- **SpiritualAlignmentMeter**: Real-time spiritual alignment feedback

## Features

- Prophetic reasoning combined with data discernment
- Real-time collaboration across cultures
- AI-augmented critical thinking tools
- Kingdom impact measurement
- ScrollXP reward system integration

## Usage

```tsx
import { CriticalThinkingDashboard } from '@/components/critical-thinking';

function App() {
  return <CriticalThinkingDashboard userId="user_123" />;
}
```

## Integration

These components integrate with:
- CriticalThinkingService (backend)

- ScrollXP reward system
