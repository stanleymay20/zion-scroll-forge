# Spiritual Formation and Discipleship

## Course Information
- **Code**: SPIRFORM_101
- **Credits**: 3
- **Level**: Foundation
- **Modules**: 8
- **Total Lectures**: 32

## Description
Deep dive into spiritual disciplines, character formation, and discipleship practices
