## **Part 1: Multiple Choice Questions (10 Questions)**  

### **1. What is the primary purpose of a loss function in machine learning?**  
A) To measure the accuracy of predictions  
B) To optimize model parameters by minimizing error  
C) To increase computational efficiency  
D) To visualize data distributions  

**Answer:** B) To optimize model parameters by minimizing error  
**Explanation:** The loss function quantifies how far the model's predictions are from the true values, guiding optimization algorithms (e.g., gradient descent) to adjust weights for better performance.

B) "Love your neighbor as yourself" (Mark 12:31)  
C) "The love of money is a root of all evil" (1 Timothy 6:10)  
D) All of the above  

**Answer:** D) All of the above  
**Explanation:** Ethical AI should ensure fairness (justice), avoid exploitation (greed), and prioritize human dignity (love).

### **3. What is the key difference between supervised and unsupervised learning?**  
A) Supervised learning requires labeled data; unsupervised does not  
B) Unsupervised learning always performs better  
C) Supervised learning is only for classification  
D) Unsupervised learning requires human intervention  

**Answer:** A) Supervised learning requires labeled data; unsupervised does not  
**Explanation:** Supervised learning trains models on input-output pairs, while unsupervised learning finds patterns in unlabeled data (e.g., clustering).  

---  

### **4. Which neural network architecture is best suited for image recognition?**  
A) Recurrent Neural Network (RNN)  
B) Convolutional Neural Network (CNN)  
C) Multilayer Perceptron (MLP)  
D) Transformer  

**Answer:** B) Convolutional Neural Network (CNN)  
**Explanation:** CNNs use filters to detect spatial hierarchies in images, making them ideal for computer vision tasks.  

---  

### **5. How does overfitting manifest in a machine learning model?**  
A) High training accuracy but poor generalization  
B) Low training and test accuracy  
C) Equal performance on training and test sets  
D) Model fails to converge  

**Answer:** A) High training accuracy but poor generalization  
**Explanation:** Overfitting occurs when a model memorizes training data noise instead of learning generalizable patterns.

### **6. Which ethical concern is most relevant in AI bias?**  
A) Computational cost  
B) Discrimination against marginalized groups  
C) Model interpretability  
D) Training time  

**Answer:** B) Discrimination against marginalized groups  
**Explanation:** Bias in AI can reinforce systemic inequalities, violating biblical justice (Proverbs 31:8-9).

### **7. What is the role of activation functions in neural networks?**  
A) To normalize input data  
B) To introduce non-linearity into the model  
C) To reduce overfitting  
D) To speed up training  

**Answer:** B) To introduce non-linearity into the model  
**Explanation:** Without activation functions (e.g., ReLU, Sigmoid), neural networks would only learn linear relationships.

### **9. What is the purpose of cross-validation?**  
A) To test a model on unseen data  
B) To reduce model complexity  
C) To ensure reproducibility  
D) To visualize data  

**Answer:** A) To test a model on unseen data  
**Explanation:** Cross-validation (e.g., k-fold) evaluates model robustness by partitioning data into training and validation sets.
