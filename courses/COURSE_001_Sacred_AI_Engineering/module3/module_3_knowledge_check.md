## **Multiple Choice Questions (10 Questions)**  

### **1. What is the primary purpose of a loss function in machine learning?**  
A) To measure the difference between predicted and actual values  
B) To optimize the learning rate  
C) To initialize model weights  
D) To visualize training data  

**Answer:** **A**  
**Explanation:** The loss function quantifies how well the model performs by comparing predictions to actual values, guiding the optimization process.

### **2. Which biblical principle aligns with the concept of fairness in AI?**  
A) "Do not muzzle an ox while it is treading out the grain" (1 Timothy 5:18)  
B) "Love your neighbor as yourself" (Mark 12:31)  
C) "The love of money is a root of all kinds of evil" (1 Timothy 6:10)  
D) "Let your light shine before others" (Matthew 5:16)  

**Answer:** **B**  
**Explanation:** Fairness in AI ensures unbiased treatment, reflecting Christ-like love for others by preventing discrimination.  

---  

### **3. Which neural network architecture is best suited for sequential data?**  
A) Convolutional Neural Network (CNN)  
B) Recurrent Neural Network (RNN)  
C) Multilayer Perceptron (MLP)  
D) Generative Adversarial Network (GAN)  

**Answer:** **B**  
**Explanation:** RNNs process sequential data (e.g., time series, text) by maintaining hidden states across time steps.  

---  

### **4. Overfitting in machine learning can be compared to which biblical warning?**  
A) "Pride goes before destruction" (Proverbs 16:18)  
B) "Do not be conformed to this world" (Romans 12:2)  
C) "A double-minded man is unstable" (James 1:8)  
D) "Do not put new wine into old wineskins" (Matthew 9:17)  

**Answer:** **A**  
**Explanation:** Overfitting occurs when a model is too complex (pride in performance) and fails to generalize, leading to poor real-world results.

### **5. What is the role of a validation set in model training?**  
A) To test the final model on unseen data  
B) To fine-tune hyperparameters during training  
C) To store historical training data  
D) To replace the need for a test set  

**Answer:** **B**  
**Explanation:** The validation set helps adjust hyperparameters (e.g., learning rate) without leaking test data information.

A) Transparency  
B) Accountability  
C) Fairness  
D) Explainability  

**Answer:** **C**  
**Explanation:** Fairness ensures AI does not produce biased or deceptive outcomes, aligning with God’s justice.

### **7. What does backpropagation accomplish in neural networks?**  
A) Randomly initializes weights  
B) Adjusts weights to minimize loss  
C) Increases model complexity  
D) Converts data into features  

**Answer:** **B**  
**Explanation:** Backpropagation calculates gradients to update weights, improving prediction accuracy.

### **8. How does AI transparency relate to Ephesians 5:13 ("Everything exposed by the light becomes visible")?**  
A) AI should be explainable to users  
B) AI should avoid biases  
C) AI should prioritize efficiency  
D) AI should replace human judgment

**Explanation:** Transparency ensures AI decisions are understandable, reflecting biblical truth and openness.

### **9. Which technique helps prevent overfitting?**  
A) Increasing model complexity  
B) Using dropout regularization  
C) Reducing training epochs  
D) Removing validation data  

**Answer:** **B**  
**Explanation:** Dropout randomly deactivates neurons during training, preventing over-reliance on specific features.
